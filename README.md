# Web Development Coursework

A centralized repository tracking my progression through my web development coursework. This contains a collection of assignments and micro-projects demonstrating my transition from foundational markup to modern front-end development.

"A progressive collection of web development coursework, tracking my journey from foundational HTML/CSS to modern React and Tailwind applications."

## Progression & Technologies

This repository documents my learning curve across the following technologies:
* **Foundational:** HTML5, CSS3, Vanilla JavaScript
* **Frameworks & Styling:** React, Tailwind CSS v4, Vite

## Repository Structure

Each folder contains a distinct assignment with its own specific learning objectives:

* **`01-HTML-Basics/`**: Semantic HTML structuring and basic web page layout.
* **`02-CSS-Styling/`**: Introduction to CSS, responsive design principles, and media queries.
* **`03-JS-Fundamentals/`**: DOM manipulation, event handling, and basic JavaScript logic.
* *(Note: Major projects, such as full-stack applications or complex React clones, are hosted in their own dedicated repositories on my GitHub profile).*

## How to Run Locally

Most foundational assignments can be viewed directly by opening the `index.html` file in a browser. 
For projects utilizing Vite/React:

1. Navigate to the specific project directory: `cd project-folder-name`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
